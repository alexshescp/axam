# Why we built Axam Studio

We spent too long looking for a terminal editor that felt like a **normal** editor.

On Linux boxes. On macOS Terminal and iTerm. Over SSH. Inside tmux and screen. In PowerShell sessions that still need a serious text tool. The gap was always the same:

- modal editors demand a second brain for day-to-day config work;
- ultra-minimal editors are honest but thin;
- “desktop shortcuts in the terminal” demos fall apart the moment Command never reaches the process;
- packaging and saves are often afterthoughts.

Coders Club (USA), Codepolder (Netherlands), and Aleksandr Shaman wanted one binary we could hand to operators and developers without a tutorial lecture.

So we wrote **Axam Studio**:

- modeless by default;
- menus and a palette that share one command table;
- keymap profiles that are compatibility maps, not cosplay;
- pending files that do not litter the disk;
- safe saves and a doctor command that tells the truth about the current tty;
- GPL so the team — and anyone else — can keep it.

If you have been searching for the same missing piece, install `axam`, press F10, and see whether the search is over.
